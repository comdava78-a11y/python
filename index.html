Основы Python

Python — высокоуровневый язык программирования с простым и понятным синтаксисом. Он идеально подходит для начинающих.

Переменные

В Python не нужно объявлять тип переменной — он определяется автоматически:

# Целое число age = 25 # Дробное число price = 19.99 # Строка name = "Анна" # Логическое значение is_student = True # Вывод значений print(f"Имя: {name}, Возраст: {age}")

Операторы

# Арифметические операторы a = 10 b = 3 print(a + b) # Сложение: 13 print(a - b) # Вычитание: 7 print(a * b) # Умножение: 30 print(a / b) # Деление: 3.333... print(a // b) # Целочисленное деление: 3 print(a % b) # Остаток от деления: 1 print(a ** b) # Возведение в степень: 1000

Типы данных

Списки (list)

Упорядоченная изменяемая коллекция элементов:

# Создание списка fruits = ["яблоко", "банан", "апельсин"] # Доступ по индексу print(fruits[0]) # яблоко print(fruits[-1]) # апельсин (последний) # Методы списка fruits.append("груша") # Добавить в конец fruits.insert(1, "киви") # Вставить по индексу fruits.remove("банан") # Удалить элемент fruits.pop() # Удалить последний # Срезы print(fruits[1:3]) # Элементы с 1 по 2 print(fruits[::2]) # Каждый второй

Словари (dict)

Коллекция пар ключ-значение:

# Создание словаря person = { "name": "Иван", "age": 30, "city": "Москва" } # Доступ к значениям print(person["name"]) # Иван print(person.get("age")) # 30 # Изменение и добавление person["age"] = 31 person["job"] = "программист" # Методы словаря print(person.keys()) # Все ключи print(person.values()) # Все значения print(person.items()) # Пары ключ-значение

Кортежи (tuple)

Неизменяемая упорядоченная коллекция:

coordinates = (55.75, 37.62) print(coordinates[0]) # 55.75 # Распаковка кортежа lat, lon = coordinates print(f"Широта: {lat}, Долгота: {lon}")

Множества (set)

Неупорядоченная коллекция уникальных элементов:

numbers = {1, 2, 3, 2, 1} print(numbers) # {1, 2, 3} # Операции с множествами a = {1, 2, 3} b = {2, 3, 4} print(a | b) # Объединение: {1, 2, 3, 4} print(a & b) # Пересечение: {2, 3} print(a - b) # Разность: {1}

class Person: """Класс, представляющий человека""" # Конструктор def __init__(self, name, age): self.name = name # Публичный атрибут self._age = age # Защищённый атрибут self.__id = id(self) # Приватный атрибут # Метод экземпляра def introduce(self): return f"Меня зовут {self.name}, мне {self._age} лет" # Свойство (property) @property def age(self): return self._age @age.setter def age(self, value): if value > 0: self._age = value # Создание объекта person = Person("Анна", 25) print(person.introduce())

Наследование

class Animal: def __init__(self, name): self.name = name def speak(self): raise NotImplementedError class Dog(Animal): def speak(self): return f"{self.name} говорит: Гав!" class Cat(Animal): def speak(self): return f"{self.name} говорит: Мяу!" # Полиморфизм animals = [Dog("Бобик"), Cat("Мурка")] for animal in animals: print(animal.speak())

Магические методы

class Vector: def __init__(self, x, y): self.x = x self.y = y def __add__(self, other): return Vector(self.x + other.x, self.y + other.y) def __str__(self): return f"Vector({self.x}, {self.y})" def __repr__(self): return self.__str__() v1 = Vector(1, 2) v2 = Vector(3, 4) print(v1 + v2) # Vector(4, 6)

Асинхронное программирование

Async позволяет выполнять множество операций ввода-вывода одновременно без блокировки.

import asyncio import aiohttp # Базовая корутина async def hello(): print("Привет") await asyncio.sleep(1) print("Мир") # Запуск asyncio.run(hello()) # Параллельное выполнение async def fetch_url(session, url): async with session.get(url) as response: return await response.text() async def main(): urls = [ "https://python.org", "https://pypi.org", "https://docs.python.org" ] async with aiohttp.ClientSession() as session: tasks = [fetch_url(session, url) for url in urls] results = await asyncio.gather(*tasks) return results # asyncio.gather() запускает все задачи параллельно results = asyncio.run(main())

Flask

Flask — лёгкий и гибкий веб-фреймворк для Python.

from flask import Flask, request, jsonify app = Flask(__name__) # Простой маршрут @app.route("/") def home(): return "Привет, Flask!" # Маршрут с параметром @app.route("/user/<username>") def user_profile(username): return f"Профиль: {username}" # JSON API @app.route("/api/data", methods=["GET", "POST"]) def api_data(): if request.method == "POST": data = request.get_json() return jsonify({"received": data}), 201 return jsonify({"message": "Привет, API!"}) if __name__ == "__main__": app.run(debug=True)

FastAPI

FastAPI — современный, быстрый фреймворк с автоматической валидацией и документацией.

from fastapi import FastAPI from pydantic import BaseModel from typing import Optional app = FastAPI() # Модель данных с валидацией class Item(BaseModel): name: str price: float is_available: Optional[bool] = True # GET-запрос @app.get("/") async def root(): return {"message": "Привет, FastAPI!"} # Параметры пути @app.get("/items/{item_id}") async def read_item(item_id: int, q: Optional[str] = None): return {"item_id": item_id, "query": q} # POST с валидацией @app.post("/items/") async def create_item(item: Item): return {"item": item.dict(), "status": "created"}

Часто задаваемые вопросы

Всегда выбирайте последнюю стабильную версию Python 3.x (например, 3.12 или 3.13). Python 2 больше не поддерживается с 2020 года.

Список (list) — изменяемый, можно добавлять и удалять элементы. Кортеж (tuple) — неизменяемый, после создания его нельзя изменить. Кортежи быстрее и используют меньше памяти.

Виртуальные окружения изолируют зависимости каждого проекта. Один проект может использовать Django 3.2, другой — Django 4.0, и они не будут конфликтовать.

Flask проще для начинающих и отлично подходит для небольших проектов. FastAPI — современнее, быстрее, имеет встроенную валидацию и автоматическую документацию API. Для новых API-проектов рекомендуется FastAPI.

Файл __init__.py делает директорию Python-пакетом. Он может быть пустым или содержать код инициализации пакета. В Python 3.3+ для namespace packages он не обязателен, но рекомендуется для явности.

self — это ссылка на текущий экземпляр класса. Он передаётся автоматически в методы класса и используется для доступа к атрибутам и методам объекта. Имя self — это соглашение, технически можно использовать любое имя.

Асинхронный код полезен для операций ввода-вывода: HTTP-запросы, работа с файлами, базами данных. Он позволяет не блокировать программу во время ожидания. Для CPU-интенсивных задач лучше использовать многопоточность или multiprocessing.
